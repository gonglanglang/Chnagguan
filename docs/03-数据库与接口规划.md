# 「过关啦」数据库与接口规划文档

> **文档版本**：v2.2（全端规范数学学习阶段体系 + 跨年级连刷 + 2500字更新日志 + OSS自定义域名直连）  
> **说明**：本文档作为前后端联调、建表与代码生成的契约基准，真实建表详见 `backend/src/main/resources/db/schema.sql` 与 `SchemaUpgradeRunner`。

> [!NOTE]
> **v2.0 ~ v2.2 数据库与接口增量**：
> - `edu_realm` 表保留底层物理表名与字段名兼容（`realm_code`、`realm_name`、`realm_order`、`grade_code`、`difficulty_label`、`unlock_gates`、`exam_question_count`、`exam_pass_score`），面向用户与管理后台统一升级为 **六大学习阶段（初一 / 初二 / 初三 / 高一 / 高二 / 高三）与阶段升级测评**；`SchemaUpgradeRunner` 启动时幂等迁移存量名称与公告。
> - `sys_config.config_value` 升级为 `TEXT`，支持最多 **2500 字** 的 `app_update_notes` 更新说明，并新增 `oss_custom_domain` 支持后台免重启配置 OSS 自定义加速域名。
> - `POST /api/app/quiz/submit` 返回 `nextGateId`、`nextGateIndex`、`nextGateName`、`nextChapterId`、`nextChapterName`、`nextGateCrossChapter` 及新增 **`nextGradeCode`、`nextGradeName`、`nextGateCrossGrade`**，支持「同章下一关 → 同年级下一章第 1 关 → 下一年级第 1 章第 1 关」连续刷题（并支持游客传 `guestPassedGateIds`）。
> - `GET /api/app/version/latest` 与 `GET /api/admin/app/version/latest` 新增 `downloadChannel`（`OSS_DIRECT` / `SERVER_PROXY` / `EXTERNAL_DIRECT` / `LOCAL`）与 `ossCustomDomain`，配置绑定 OSS 的自定义域名后学生端即可在 App 内直接从 OSS 高速下载 APK（不跳转浏览器）。

## 一、核心 MySQL 数据库设计

所有表使用 `InnoDB` + `utf8mb4_unicode_ci`（确保 Emoji 如 `🌱🐉` 与数学符号 `∈∪∩√²³−` 正常存储）。

### 1.1 表清单总览

| 分类 | 表名 | 用途说明 |
|---|---|---|
| 用户与权限 | `app_user` | 前台学生用户基础信息与累计战绩汇总 |
| 用户与权限 | `sys_admin` | 管理后台管理员 / 教研账号 |
| 用户与权限 | `sys_oper_log` | 后台高危操作与内容变更审计日志 |
| 教研与题库 | `edu_grade` | 年级表（初一 `g7` ~ 高三 `h3`） |
| 教研与题库 | `edu_chapter` | 章节表（起步 51 章，支持后台新增自定义章节） |
| 教研与题库 | `edu_gate` | 关卡配置表（每章 4 关：基础/中档/拓展/压轴） |
| 教研与题库 | `edu_question` | 题目主表（支持静态单选题与动态参数模板题） |
| 教研与题库 | `edu_level_rule` | 创意段位规则表（起步 10 个段位） |
| 闯关与错题 | `user_gate_progress` | 用户关卡通关状态表（决定下一关解锁与星星数） |
| 闯关与错题 | `user_quiz_record` | 每次闯关/重做答题记录表（含题目快照与得分） |
| 闯关与错题 | `user_wrong_question` | 用户错题本表（记录错题、次数、已掌握状态） |
| 闯关与错题 | `user_essay_answer` | 学生解答题作答记录与老师批注（同境界+同章节+同关卡保留最新1条覆盖） |
| 修炼课程 | `edu_video_series` | 教学视频系列表（标题、封面、简介、绑定境界、上下架） |
| 修炼课程 | `edu_video_lesson` | 教学视频课时表（所属系列、视频地址、标题、课堂笔记、排序） |
| 首页运营 | `edu_home_banner` | 首页师资力量轮播图表（封面图、标题、副标题、富文本详情 HTML、排序与上下架） |
| 系统配置 | `sys_config` | 全局开关与运营参数（如游客试玩开关、公告） |

```sql
CREATE TABLE app_user (

  wx_unionid VARCHAR(64) DEFAULT NULL COMMENT '微信UnionID',

  avatar_url VARCHAR(255) DEFAULT '' COMMENT '头像地址',
  grade_code VARCHAR(16) DEFAULT 'g7' COMMENT '当前在读年级代码 g7/g8/g9/h1/h2/h3',
  passed_gate_count INT NOT NULL DEFAULT 0 COMMENT '累计已过关数（冗余统计加速查询）',
```

#### 5) 题目表 `edu_question`（弹性结构：兼容静态/动态模板 + 后续新增多题型变化）
> 已同步落地于 [schema.sql](../backend/src/main/resources/db/schema.sql)，支持后续题目结构变化而无需破坏历史记录。

```sql
CREATE TABLE edu_question (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  grade_code VARCHAR(16) NOT NULL,
  chapter_id BIGINT UNSIGNED NOT NULL,
  gate_id BIGINT UNSIGNED NOT NULL,
  question_mode VARCHAR(24) NOT NULL DEFAULT 'STATIC' COMMENT 'STATIC静态 / DYNAMIC_TEMPLATE动态随机',
  question_format VARCHAR(24) NOT NULL DEFAULT 'SINGLE_CHOICE' COMMENT 'SINGLE_CHOICE单选 / MULTI_CHOICE多选 / FILL_BLANK填空 / JUDGE判断 / ESSAY解答',
  stem TEXT NOT NULL COMMENT '题干（动态题可存示例或模板）',
  options_json JSON DEFAULT NULL COMMENT '选项 JSON 数组（不固定数量，支持2~6项；解答题为空数组）',
  answer_json JSON NOT NULL COMMENT '标准答案 JSON，如 {"index":0}、{"indexes":[0,2]}、{"values":["3"]}、{"text":"参考解答"}',
  analysis TEXT DEFAULT NULL COMMENT '题目解析（可选）',
  generator_code VARCHAR(64) DEFAULT NULL COMMENT '内置动态生成器编码',
  template_rule_json JSON DEFAULT NULL COMMENT '动态模板规则 JSON（PARAM_TEMPLATE / PROTOTYPE_JS_EXPR）',
  difficulty TINYINT NOT NULL DEFAULT 1 COMMENT '难度星级 1~5',
  tags_json JSON DEFAULT NULL COMMENT '知识点标签 JSON 数组',
  ext_json JSON DEFAULT NULL COMMENT '扩展配置 JSON（配图/公式模式/分值等免改表扩展）',
  source VARCHAR(24) NOT NULL DEFAULT 'ADMIN' COMMENT '来源：PROTOTYPE / ADMIN / IMPORT',
  version INT NOT NULL DEFAULT 1 COMMENT '内容版本号（每次实质修改自增）',
  sort_order INT NOT NULL DEFAULT 0,
  enabled TINYINT NOT NULL DEFAULT 1 COMMENT '1上架 0下架',
  created_by BIGINT UNSIGNED DEFAULT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted TINYINT NOT NULL DEFAULT 0,
  PRIMARY KEY (id),
  KEY idx_q_gate_enabled (gate_id, enabled, deleted),
  KEY idx_q_grade_chap (grade_code, chapter_id, question_mode, question_format)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='弹性题库主表';
```

#### 9.1) 解答题作答与手写画板记录表 `user_essay_answer`

```sql
CREATE TABLE user_essay_answer (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  session_no VARCHAR(64) NOT NULL COMMENT '所属答题会话流水号',
  item_index INT NOT NULL DEFAULT 0 COMMENT '会话内题号',
  user_id BIGINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '学生ID（0表示游客）',
  question_id BIGINT UNSIGNED DEFAULT NULL,
  grade_code VARCHAR(16) NOT NULL DEFAULT '',
  realm_code VARCHAR(24) NOT NULL DEFAULT '' COMMENT '所属境界编码',
  chapter_id BIGINT UNSIGNED DEFAULT NULL,
  chapter_name VARCHAR(100) NOT NULL DEFAULT '',
  gate_id BIGINT UNSIGNED DEFAULT NULL COMMENT '所属关卡ID',
  gate_name VARCHAR(32) NOT NULL DEFAULT '',
  stem TEXT NOT NULL COMMENT '作答时具体题干快照',
  reference_answer TEXT DEFAULT NULL COMMENT '参考答案/评分要点快照',
  answer_text TEXT DEFAULT NULL COMMENT '学生文字作答补充',
  answer_image_key VARCHAR(512) DEFAULT NULL COMMENT '阿里云OSS私有对象键（读取时动态签名）',
  self_correct TINYINT DEFAULT NULL COMMENT '学生自评：1正确 0有误 NULL待核',
  teacher_status TINYINT NOT NULL DEFAULT 0 COMMENT '老师批改：0待批改 1通过 2待订正',
  teacher_comment VARCHAR(512) NOT NULL DEFAULT '',
  teacher_image_key VARCHAR(512) DEFAULT NULL COMMENT '老师PC画板批注图OSS对象键',
```

## 二、混合出题引擎设计（兼容原版 136 个动态关）

原版题库中 68 关为静态题（`qs`）、136 关为函数动态题（`gen`）。在 Java 后端通过 `QuestionEngineService` 统一封装两种出题方式：

1. **静态题 (`STATIC`)**：直接从 `edu_question` 中筛选启用题目（随机抽取 `gate.question_count` 道或按排序取题），如需要可对选项做服务端洗牌并重算 `answerIndex`。
2. **动态模板题 (`DYNAMIC_TEMPLATE`)**：
   - **路径 A（原版 136 关平滑迁移）**：每道原版生成器函数在 Java 中实现为带编码的受控生成器（如 `G7_C1_G1_1`、`G7_C3_G2_2` 等），内置 `R(min, max)`、`frac(n, d)`、`mkg(q, ans, wrongs)` 公共工具方法，保证与原版完全一致的数学精度和中文题干；
   - **路径 B（后台可视化新增参数化动态题）**：教研在后台可配置受控 JSON 规则，例如：
     ```json
     {
       "vars": { "a": [2, 9], "b": [1, 8] },
       "stemTpl": "若 |x - {{a}}| + |y + {{b}}| = 0，则 x + y =",
       "ansExpr": "a - b",
       "wrongExprs": ["a + b", "-a + b", "-a - b"]
     }
     ```
     后端使用受限算术求值器（仅允许加减乘除与变量名，禁止方法调用与脚本执行）生成具体题干、答案与 3 个不重复干扰项并洗牌。
3. **交卷一致性保证**：无论静态还是动态生成，一旦在 `POST /api/app/quiz/start` 生成题目，即把具体题干、洗牌后选项、真实答案索引写入 `user_quiz_record.question_snapshot_json` 与 Redis 会话，返回给客户端的仅含 `{ itemIndex, stem, options }`，彻底杜绝前端抓包看答案。
