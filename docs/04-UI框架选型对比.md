# UI 框架选型对比与建议

> **当前状态**：✅ **已最终确认采用 `Wot Design Uni`（基于开源 `vue-uniapp-template` + `@wot-ui/ui` v2 底座打造，管理后台已基于 `pure-admin-thin` + `Element Plus` 落地）**。本文保留选型对比记录作为架构决策档案。

---

## 一、学生端 UniApp UI 框架对比（Vue 3 + TypeScript）

结合本项目特性：**绿色清新教育风（卡片、进度条、单选选项组、弹窗、Toast、表单、Tag 徽章）+ 需兼容微信小程序与 H5/App + Vue 3 / TS**，为您精选以下三款主流方案：

| 对比维度 | **Wot Design Uni**（首选推荐 ⭐） | **uView Plus**（经典备选） | **uni-ui**（官方极简备选） |
|---|---|---|---|
| **定位与底层** | 专门面向 Vue 3 + TS 的现代 UniApp 组件库 | uView 2.x 的 Vue 3 升级版，老牌社区生态大 | DCloud 官方组件库 |
| **TypeScript 支持** | ⭐⭐⭐⭐⭐ 原生 TS 编写，类型提示极完整 | ⭐⭐⭐ 逐步补全中，部分组件类型偏弱 | ⭐⭐⭐ 基础 TS 声明 |
| **多端兼容性** | 微信/支付宝/钉钉小程序 + H5 + App 均表现稳定 | 微信/H5 成熟，个别复杂组件在部分小程序需调试 | ⭐⭐⭐⭐⭐ 官方出品，全端兼容与稳定性最高 |
| **视觉与主题定制** | 现代简洁圆润，内置 CSS 变量易于定制为「过关绿 `#16a34a`」 | 默认偏企业蓝，样式较丰富但整体偏厚重 | 样式朴素基础，几乎都需要自行写大量 CSS 美化 |
| **组件丰富度** | 70+ 高频组件（Cell、Popup、Steps、Tag、Toast、Picker、Tabs 等全覆盖） | 80+ 组件，业务杂项组件最全 | 30+ 基础组件（无内置丰富弹窗/徽章样式） |
| **包体积与性能** | 按需引入（easycom），体积轻巧 | 相对略大，历史依赖偏多 | 体积最小 |
| **官网参考** | `wot-design-uni.cn` | `uview-plus.jiangruyi.com` | `uniapp.dcloud.net.cn/component/uniui/uni-ui.html` |

### 推荐结论
- **首选推荐：`Wot Design Uni`**
  - 原因：本项目学生端界面并不复杂（核心是卡片、进度条、题目选项、弹出确认框、段位徽章、筛选标签），**清爽颜值 + 良好的 Vue 3 / TS 体验 + 小程序包体积控制**比堆砌冷门大组件更重要，Wot Design Uni 契合度最高。
- **如果您此前用惯了 uView 2**，想复用过去组件习惯，也可选择 **`uView Plus`**。
- **如果希望极致轻量、完全靠自己手写样式还原原版 PWA 风格**，可选 **`uni-ui`**。

## 二、管理后台 UI 框架建议（Web 端）

管理后台需要高频用到：**带搜索条件的分页表格、详情抽屉、题目编辑弹窗、树形章节结构、Excel 导入弹窗、图表看板**。

| 对比维度 | **Element Plus**（首选推荐 ⭐） | **Arco Design Vue** / **Ant Design Vue** |
|---|---|---|
| **生态成熟度** | Vue 3 后台管理事实标准，资料和排错案例最多 | 大厂风格，视觉更现代，配置项相对更细致 |
| **上手效率** | 极高，与 UniApp 同为 Vue 3 语法，切换几乎零成本 | 中高 |
| **适合场景** | 教研题目表单、用户详情抽屉、批量导入与后台 CRUD | 偏重数据中台 / 复杂交互系统 |

- **推荐选择**：**`Element Plus`**（+ `ECharts` 用于仪表盘统计图）。
